# 💸 App Controle de Gastos

Aplicação web para controle de gastos pessoais, desenvolvida durante a **Imersão Tech Angular** da [WoMakersCode](https://womakerscode.org/).

## 🚀 Tecnologias

- [Angular 21](https://angular.dev/)
- TypeScript
- SCSS

## ✨ Funcionalidades

- Adicionar gastos com descrição e valor
- Visualizar histórico de gastos
- (em breve) Integração com backend

## 📦 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/demartins-dev/app-controle-gastos.git

# Acesse a pasta
cd app-controle-gastos

# Instale as dependências
npm install

# Rode o projeto
npm start
```

Acesse `http://localhost:4200` no navegador.
